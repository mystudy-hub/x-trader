# 规则来源与历史公告登记 (Rule Sources)

本目录用于存放交易所官方规则公告原文索引、哈希、版本化生效区间与核验清单（对应规划 §2.5、§5.4 与需求 `FR-RULE-04`, `FR-CAL-10`）。

## 核心原则

1. **未核验不作默认**：缺一手公告原文或柜台证明的规则，登记为“缺口”，不得作为实盘默认参数。
2. **时效版本化**：每条手续费率、保证金比例、交易时段规则必须声明：
   - `effective_basis`: 原公告以交易日还是物理时刻生效，保留原始口径。
   - `effective_from` / `effective_to`: 规范化后的生效时刻，区间左闭右开，支持日内调整；当前无结束时刻时为 null。
   - `effective_trading_day`: 按交易日生效时保留原始交易日，由版本化夜盘日历映射实际时刻，不能直接按自然日零点切换。
   - `announced_at`: 公告发布时间。
   - `known_at` / `available_at`: 查询者实际可获知的时刻，区别于业务生效时刻；策略查询不得读取未来版本。
   - `source_url` / `source_file_sha256`: 官方原文链接及快照哈希
3. **首个工程样本基准**：
   - 上期所螺纹钢 (`SHFE.rb`)
   - 规则与时段参照 [docs/references/中国期货交易时间段与集合竞价机制详解.md](../../docs/references/中国期货交易时间段与集合竞价机制详解.md)。

本目录保存来源索引与证据说明。运行时规则数据库位于 `data_storage/meta/control.db`，不提交 Git。原公告、适用范围、替代关系和核验状态按 [09 规则核验清单](../../docs/09_前期准备与规则核验清单.md) 登记；目录规范建立不表示这些证据已取得。
