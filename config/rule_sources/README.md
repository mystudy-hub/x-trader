# 规则来源与历史公告登记 (Rule Sources)

本目录用于存放交易所官方规则公告原文索引、哈希、版本化生效区间与核验清单（对应规划 §2.5、§5.4 与需求 `FR-RULE-04`, `FR-CAL-10`）。

## 核心原则

1. **未核验不作默认**：缺一手公告原文或柜台证明的规则，登记为“缺口”，不得作为实盘默认参数。
2. **时效版本化**：每条手续费率、保证金比例、交易时段规则必须声明：
   - `effective_from`: 生效开始交易日
   - `effective_to`: 生效结束交易日（当前有效则为 null）
   - `announced_at`: 公告发布时间
   - `source_url` / `source_file_sha256`: 官方原文链接及快照哈希
3. **首个工程样本基准**：
   - 上期所螺纹钢 (`SHFE.rb`)
   - 规则与时段参照 [docs/references/中国期货交易时间段与集合竞价机制详解.md](../../docs/references/中国期货交易时间段与集合竞价机制详解.md)。
