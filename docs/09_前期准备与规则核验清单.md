本文把规划第二章"前期准备清单"重组为可勾选、可追溯的核验清单，供项目负责人、接入与数据负责人在阶段 S0 逐项执行并登记证据。每一项都关联 02 文档的需求编号。本文不新增任何交易所或柜台事实；所有"须核验"项的答案来自原公告、CTP 发行包文档 / 头文件、期货公司说明与联调证据，网页或第三方汇总只作为查找线索。

## 1. 使用说明

每张清单表使用统一列：

| 列 | 含义 |
| :--- | :--- |
| 状态 | `未开始` / `进行中` / `已核验` / `登记缺口` |
| 证据位置 | 归档文件路径、哈希、脱敏联调记录编号或测试编号 |
| 核验日期 | 完成核验的日期（不是网页浏览日期） |
| 负责人 | 姓名或角色 |

原则（来源：规划 §一、§1.2、§二.5）：

- 未核验条目登记为缺口，不作为实盘默认；不因被评审或时间底稿引用就成为生产默认。
- 网页核验日期不等于规则生效日期；缺少一手原文或无法唯一判断适用版本时，登记受影响品种、时段及实验范围，不伪造历史配置。
- 规则来源、核验日期和生效时间分别保存。
- 凭证、终端采集载荷及原始终端标识不得写入本清单或任何归档附件。
