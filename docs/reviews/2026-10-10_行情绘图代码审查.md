## 发现与修复

| 级别 | 问题及复现 | 修复 |
| :--- | :--- | :--- |
| P1 | 一份存档含一条无效绘图时，整组有效绘图也不加载；随后新增绘图会覆盖原始存档。 | 逐条恢复有效且唯一的绘图；写入前备份原始字节。备份失败或存储不可读时阻止覆盖。 |
| P2 | 拖动中按 Delete 删除，随后取消操作会恢复拖动前的图形，页面状态与已保存状态不一致。 | 删除前取消未提交的拖动并释放指针捕获；撤销删除恢复拖动前的图形。 |
| P2 | `.cjs` 绘图测试未接入统一检查或 GitHub Actions，MM 计算回归可能在检查全绿时漏过。 | 统一入口加入 Node 绘图测试和前端入口语法检查，CI 安装 Node.js 22；工具缺失明确失败并继续其他检查。 |

上述问题均已修复；原有绘图类型、旧等幅线坐标及保存键保持兼容。新增 MM 箱体按 `H = P_high − P_low` 计算上方 `P_high + H / +2H`、下方 `P_low − H / −2H`，不自动判断突破。
