# 历史行情工作台

在仓库根目录启动：

```powershell
.\.venv\Scripts\python.exe scripts/serve_market_viewer.py
```

浏览器打开 http://127.0.0.1:8765 。默认读取 `data_storage/raw/tdx_weighted/20261007_5y`，可用 `--data-dir` 指定相同结构的加权归档，`--port` 更改端口。按 Ctrl+C 停止前台服务。

扩展历史通过 `data_storage/viewer_archives.json` 登记，格式为 `{"schema_version":1,"archives":["raw/tdx_weighted/20261007_FGL9_full"]}`。路径相对于 `data_storage`；后登记归档替换同一品种/周期的浏览数据，不改写原有归档，也不移除其他品种。修改登记后重启服务。玻璃已扩展至 2012-12-03；30m 的 2013-11-20 至 2019-02-15 来源缺口在状态栏和数据说明中显示。

## 已支持

- 85 个加权序列的日线、原生 30 分钟线；品种搜索、交易所筛选、按涨跌幅排序。
- K线拖动缩放、十字光标、上海时区、自然时间与交易日提示。
- EMA20/50/200 开关、成交量和持仓量副图；EMA按完整历史计算，以前N根均值初始化。
- 最近区间快捷定位、交易日起止日期定位、恢复最近150根K线。
- 浏览器本地自选列表与周期记忆、两种涨跌配色、全屏和 PNG 图表导出。
- 趋势线、射线、平行通道、价格/时间度量和 MM 箱体测算；绘图按品种及周期保存在本机浏览器。

## 在图表上画线

主图左侧工具栏提供：

| 工具 | 操作 | 快捷键 |
| :--- | :--- | :--- |
| 选择 | 点击线条选中；拖端点调整，拖线条整体平移 | V |
| 趋势线 | 依次点击起点、终点 | T |
| 射线 | 点击起点，再点击方向点，沿该方向延伸到图表边缘 | R |
| 平行通道 | 点基线起点、终点，再点第三点确定通道宽度；两条边线保持平行 | P |
| 度量 | 依次点击起点、终点，显示价差、百分比、K线间隔和自然时间跨度 | M |
| MM箱体测算 | 点击平台两角确定上下轨，同时显示上破、下破各 1× 和 2× 目标位 | D |

MM（Measured Move）以箱体垂直高度测算：自动取两角价格的最大值为上轨 `P_high`、最小值为下轨 `P_low`，`H = P_high − P_low`，不依赖点击顺序。上下轨按当前图表价格显示精度取值。

| 条件 | 1× MM | 2× MM |
| :--- | :--- | :--- |
| 向上突破上轨 | `P_high + H` | `P_high + 2H` |
| 向下跌破下轨 | `P_low − H` | `P_low − 2H` |

例如下轨100、上轨110，H=10：上方目标为120、130，下方目标为90、80。箱体表示选定的平台范围，四条水平目标线向右延伸；1×为虚线，2×为实线。目标超出当前纵轴仍显示价格及“视野外”提示。拖动两角可调整箱体并重算目标，拖动边线或目标标签可整体平移。

该工具不自动判断突破是否确认，也不预测目标到达时间。此前已经保存的两点等幅线保持原有位置与 `B+(B−A)` 目标，改标为“等幅目标（旧）”，不再误称箱体2× MM。新建MM使用独立的箱体类型，保存、撤销、周期隔离和图片导出沿用其他绘图工具。

Esc 取消未完成绘图；Delete / Backspace 删除选中绘图；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。左侧色块可改变新绘图或当前选中绘图的颜色；眼睛按钮临时隐藏/显示绘图，不删除数据。

绘图锚点保存为时间、K线内偏移和价格，缩放、平移、价格轴调整后会重新投影。新增更早历史时，原有时间锚点不会因为K线序号改变而整体错位。品种和周期各自保存，未完成绘图在切换时取消；撤销历史只保留当前页面的当前品种/周期。每个图表最多保存200个绘图，绘图数据位于浏览器localStorage，清理站点数据会清除这些记录。

若存档中个别绘图异常，仍会加载有效绘图；下次保存前先将原始内容备份到同一存储键的 `:recovery:<唯一标识>` 项。备份失败或存储不可读时不会覆盖原记录，新操作暂留当前页面。拖动中删除会先取消未提交的拖动，撤销删除恢复拖动前的图形。

度量中的时间跨度包含周末和休市；K线间隔按实际加载的数据计算，不能视为已核验的交易时长。落在已有数据之外的端点按标称周期估算时间，并显示“估算”。PNG 导出包含已显示的绘图及度量标记。

图表库为固定版本的 TradingView Lightweight Charts™ 5.2.1，文件在 `web/vendor`；打开看盘页面无需在线加载外部脚本。授权与署名见 `web/THIRD_PARTY.md`。本页面不是 TradingView 官方产品，不支持 Pine Script。

## 行情时间与质量

顶部价格和侧边栏涨跌幅来自最后两根日线，明确标注历史快照日期，不表示实时行情。主图悬停显示该根K线的 OHLC，状态栏显示交易日。

30m保留原始价格和分桶，将来源标在交易日上的晚间数据映射到前一来源交易日；凌晨映射到该夜盘自然日期的次日，随后才是交易日日盘。例如周一交易日的21:30显示在周五21:30，其00:30显示在周六00:30。区间首日可从已归档的日线原始分页获得前序交易日；无证据则排除对应夜盘，数量在“数据与时间口径”中显示。该转换仅供历史浏览，不等于正式交易日历验收，不改变原始CSV。

来源缺成交额、官方结算价，部分不活跃品种存在分钟日期缺口；加权算法和原生跨休市分桶尚未独立核验。页面不补造缺失行情。每日收盘价与30m末值如有来源差异，分别保留。

服务仅监听本机 `127.0.0.1`，提供固定静态资源和只读行情 API，不接账户或下单通道。回测成交标记和实时行情接入属于后续功能，本版先完成历史行情浏览。
